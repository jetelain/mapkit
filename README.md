# MapKit

A collection of .NET libraries and tools for map processing, Digital Elevation Models (DEM) and map rendering.

## Packages

| Package | NuGet | Description |
| ------- | ----- | ----------- |
| [Pmad.Cartography](MapToolkit/) | [![NuGet](https://img.shields.io/nuget/v/Pmad.Cartography)](https://www.nuget.org/packages/Pmad.Cartography) | DEM processing: elevation queries, contour lines, hillshading, file I/O |
| [Pmad.Drawing](Pmad.Drawing/) | [![NuGet](https://img.shields.io/nuget/v/Pmad.Drawing)](https://www.nuget.org/packages/Pmad.Drawing) | Vector drawing API with SVG, PNG/WebP and PDF backends |
| [Pmad.Cartography.Drawing](Pmad.Cartography.Drawing/) | [![NuGet](https://img.shields.io/nuget/v/Pmad.Cartography.Drawing)](https://www.nuget.org/packages/Pmad.Cartography.Drawing) | Topographic map rendering built on top of the two libraries above |

## Tools

| Tool | Description |
| ---- | ----------- |
| [DemUtility](DemUtility/) | CLI tool (`dem`) for managing DEM databases: indexing, repacking, integrity checks |
